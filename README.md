🏥 PatientCare – Hospital Management System

PatientCare is a web-based Hospital Management System designed to simplify and organize patient record management. It provides an easy-to-use dashboard to manage patient information, track appointments, and view patient registration statistics.

🌐 Live Demo
https://swethakadiri.github.io/hospital-management-system/ 

📌 Project Overview

The Hospital Management System helps hospital administrators manage patient details efficiently through a simple and user-friendly interface.

The application includes a dashboard, patient registration form, patient records management, appointment tracking, and reports & analytics.

✨ Features
Dashboard
View total registered patients.
View male and female patient statistics.
Monitor upcoming appointments.
View recently registered patients.
Patient Management
Add new patient details.
View patient records.
Search patients by name or patient ID.
Update and delete patient records.
Appointment Management
View patient appointment details.
Track appointment dates and status.
Reports & Analytics
View patient registration statistics.
Analyze patient gender distribution.
Download patient reports in CSV format.
Settings
View application information and preferences.
🛠️ Technologies Used

CSS3 – Styling and responsive user interface.
JavaScript – Application functionality and interactions.

🚀 Installation and Setup

Follow these steps to run the project locally.

1. Clone the repository

bash
git clone https://github.com/swethakadiri/hospital-management-system.git


2. Navigate to the project folder

bash
cd hospital-management-system


3. Open the project

Open the index.html file in your web browser.

Alternatively, use the Live Server extension in Visual Studio Code to run the application.

💻 How to Use
Open the application in your browser.
Navigate to the Dashboard to view patient statistics.
Select Add Patient to enter new patient information.
Visit Patient Records to view and search patient details.
Navigate to Appointments to view appointment information.
Open Reports & Analytics to view registration statistics.
Export reports using the CSV download option.
